# Sabella 0.2.1

Sabella 0.2.1 is a patch release that makes the 0.2.0 content installable.
The `0.2.0` tag was pushed but its release gate failed and no GitHub Release was
published: SwiftPM cannot resolve a tagged package that depends on an untagged
git revision, and 0.2.0 pinned KSPlayer by revision. Tags are immutable, so the
fix ships as a new version and `0.2.0` must not be consumed.

## What changed

- KSPlayer is now pinned to the upstream tag `2.3.4` instead of revision
  `10a40a1c0001d75307ad5922d1d1bc0cb01c89b4`. No Sabella source changed.
- All public API from 0.2.0 is unchanged, including the breaking
  `BleeckerBrandLockup.init(name:)` change documented in
  [`0.2.0.md`](0.2.0.md).

## Known trade-off

The previous revision was 33 upstream commits newer than tag `2.3.4`. Notable
fixes that `2.3.4` does not contain: audio output channel negotiation using
`preferredOutputNumberOfChannels` and `allowedAudioSpatializationFormats`, a
"fix infinity" crash fix, and the brightness/volume overlay respecting
`KSOptions`. Whether tvOS playback depends on any of them has not been verified
on a device.

## Compatibility and installation

- Swift tools 6.0
- macOS 14 or later
- iOS and iPadOS 17 or later
- tvOS 17 or later
- Compatible consumer range: `>= 0.2.1, < 0.3.0`

Authorized consumers add:

```swift
.package(
    url: "https://github.com/gaulatti/sabella.git",
    .upToNextMinor(from: "0.2.1")
)
```

Application targets continue to link only the `Sabella` product. Repository
access must come from existing developer or CI credentials; no token or deploy
key belongs in source.

## Rollback and pinning

Published tags are immutable. If 0.2.1 is unsuitable, pin the last release with
`.exact("0.1.0")`; do not move or replace any tag. A defect in 0.2.1 is
corrected in a later patch or minor release.

Verify the downloaded deterministic archive from the release directory with
`shasum -a 256 -c SHA256SUMS`.
