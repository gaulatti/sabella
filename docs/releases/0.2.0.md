# Sabella 0.2.0

Sabella 0.2.0 is the second private Swift Package Manager release of the
Gaulatti Apple-native design system. It is a pre-1.0 minor release because it
adds a substantial tvOS surface and intentionally replaces one public brand
initializer.

## Breaking change

- `BleeckerBrandLockup.init(name:image:)` is replaced by
  `BleeckerBrandLockup.init(name:)`. The lockup now renders Sabella's bundled,
  authoritative Gaulatti mark; consumers can no longer substitute arbitrary
  artwork through this component. Consumers that need separate artwork can
  compose it outside the lockup.

## Public additions

- Bundled Encode Sans and Libre Franklin faces are registered on first use, and
  `SabellaFonts` exposes registration state for integration checks.
- `BleeckerBrandMark` exposes the bundled mark as a standalone SwiftUI view.
- tvOS-only channel discovery includes home, directory, navigation, settings,
  content-card, hero, shelf, and editorial-rail contracts.
- tvOS-only live playback includes television/radio classification, channel
  guide and remote controls, foreground/background policy, bounded recovery,
  playback failure, DVR, quad-view, emergency, and broadcast surfaces.
- `SabellaTVPlaybackActivity` and the additive
  `SabellaTVLivePlayer.onPlaybackActivityChanged` callback expose coalesced,
  `Sendable` channel activity. Only `.playing` denotes advancing media.

## Package changes

- The Sabella target now bundles its brand artwork and font licenses as Swift
  package resources.
- KSPlayer is pinned by immutable revision and linked only for tvOS, alongside
  the package-owned workaround target used by live playback.
- The release consumer compiles representative application-shell APIs on macOS
  and Home/live-playback APIs for the tvOS simulator from the remote tag.
- The release publishes a deterministic `Sabella-0.2.0.tar.gz` source asset and
  a `SHA256SUMS` asset.

## Compatibility and installation

- Swift tools 6.0
- macOS 14 or later
- iOS and iPadOS 17 or later
- tvOS 17 or later
- Compatible consumer range: `>= 0.2.0, < 0.3.0`

Authorized consumers add:

```swift
.package(
    url: "https://github.com/gaulatti/sabella.git",
    .upToNextMinor(from: "0.2.0")
)
```

Application targets continue to link only the `Sabella` product. Repository
access must come from existing developer or CI credentials; no token or deploy
key belongs in source.

## Rollback and pinning

Published tags are immutable. If 0.2.0 is unsuitable, pin the last release with
`.exact("0.1.0")`; do not move or replace either tag. Reverting to 0.1.0 also
requires consumers to restore any use of the former custom-image brand-lockup
initializer and remove references to the new font and tvOS APIs. A defect in
0.2.0 is corrected in a later patch or minor release.

Verify the downloaded deterministic archive from the release directory with
`shasum -a 256 -c SHA256SUMS`.
